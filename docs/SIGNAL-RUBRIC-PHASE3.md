# Signal Rubric Phase 3 · protected product translation

Phase 3 keeps the accepted Rubric composition and makes the smallest extension
needed to express Signal's protected spatial law.

## Structural law

| Rubric primitive | Signal meaning |
| --- | --- |
| central router | Reality |
| Skills | Project Model |
| Memory | Project World |
| Routines | Attention / Open Loops |
| Applications | Source Systems |

These are renamed roles, not a replacement Signal ring system. `aligned`,
`drift`, and `conflict` never become primary rings.

## Source horizon

Source System anchors are presentation-only Rubric application nodes built
only from typed canonical fields (`kind`, `sourceType`, `lane`, `producer`).
The adapter never reads a title, excerpt, source reference, or URL prose to
guess a provider.

Each anchor carries separate artifact, passage, and claim counts. Its
membership retains every canonical member ID. Structural spokes join the
anchor to its direct typed artifacts; canonical `extracted_from`, `cites`, and
`evidenced_by` relations form the inward path. Passages inherit a provider only
from their exact canonical `extracted_from` endpoint.

Disclosure changes identity, not existence:

- Fit: large Source System anchors and roll-up counts.
- Medium: source artifacts.
- Near/close: ordinary canonical objects, passages, and quote labels.
- Selected: Rubric's card and viewer expose full identity and actions.

## Reality distance

The adapter emits a semantic `realityRelationship` and normalized
`realityDistance` only. It never emits coordinates, radius, angle, target,
camera, or physics.

The score is derived solely from canonical disagreement/blocking semantics:

- aligned/supporting/resolved: `0`
- drift/unresolved/unassessed: `0.5`
- conflict/missing/blocking: `1`

Trust, currentness, provider, and external-vs-accepted state do not participate.
The guarded Phase 3 core extension applies the score as exactly `0`, `6`, or
`12` world units on top of Rubric's own Memory row target. Rubric still owns
the row, sector, annulus, rotation, transition, drag release, and camera. The
offset is deliberately smaller than the native row gap, preserving the dense
Project World silhouette.

## Separate material channels

- attested: solid mint keyline
- inferred: dashed amber keyline
- external: dotted blue keyline
- current: white point
- superseded: grey strike

Canonical relationships remain the only relationship haze. Phase 3 preserves
their basis metadata through Rubric aggregation so the existing haze can carry
these quiet material distinctions. Structural spokes are not presented as
canonical connections.

## Exact Rubric extension boundary

The accepted Phase 1 `_core.js`, `_flows2.js`, `_core.css`, and `_icons.js`
remain untouched and byte-identical. The Phase 3 route builds its served core
from Phase 1 `_core.js` using four guarded source patches:

1. preserve canonical link metadata during Rubric aggregation;
2. define the bounded Reality-distance modifier;
3. apply it inside native Memory slot seating;
4. let semantic zoom thresholds participate in Rubric's native label budget.

If any exact source anchor moves, the route fails rather than silently creating
a divergent engine. Every other Rubric primitive remains direct.

## Fresh Audit

`Fresh Audit` opens Signal's existing `/audit/new` workflow with the current
scope preselected. That workflow ingests evidence and creates Findings through
the canonical Audit path; it does not accept Reality. `Refresh world` only
rebuilds the read-only adapter projection and uses Rubric's native data refresh,
which retains camera state and morphs the persistent world.

The current form ingests a supplied transcript/document/spreadsheet and reads
its existing Linear context. It does **not** yet initiate a provider-wide Hermes,
Notion, Figma, and document refresh. That orchestration needs an explicit
canonical refresh contract and credentials; the read-only Rubric world must not
guess it or call mutating provider APIs. This remains a Phase 3 follow-up, not a
hidden side effect of `Refresh world`.

Audit discovers. Reality governs. Signal responds.

## Layout questions

Rubric's native layout functions remain direct. The compact Audit control now
states the Signal question each one answers: Rings relates the world to Reality;
Circle and Hex expose organization/constellation; Force exposes current
structural connectivity. No alternate layout implementation is introduced.

## Audit-local presentation adjustments

The top Source System anchor keeps its native Rubric position. Its small identity
label receives an 88-pixel label-only nudge at Fit so the count does not collide
with Rubric's `SOURCE SYSTEMS` structural heading. Anchor geometry, hit testing,
camera, and physics remain unchanged.
