# Session 1 — Understand Signal

**Duration:** 30 minutes

## Objectives

By the end, the learner can explain Signal in plain English; distinguish KE/Hermes, Audit, Reality, Scenario, Forecast, and Report; read the Control Room; and state the core product laws without notes.

## Prerequisites

Read `00-HOW-TO-PLAY-SIGNAL.md`. Use production read-only with a current project; no writes.

## Walkthrough

1. **0–5 min — The problem.** Describe fragmented knowledge, task-tracker limits, and why an AI synthesis must not silently become delivery truth.
2. **5–10 min — The loop.** Walk `SIGNAL-AT-A-GLANCE`: Knowledge → Audit → Govern → Model → Forecast → Communicate.
3. **10–20 min — Control Room.** Verify project and Reality state. Read Reality, Choices, Capacity, Outcome, Time. Select one material object and follow its owner door, then return.
4. **20–25 min — Currentness.** Contrast live/current, live/stale, and historical. Open Audit freshness and Source Health without refreshing.
5. **25–30 min — Three dates.** Point to likely, target, and commitment; say what each is and who owns it.

## Exercises

- Explain Signal to a delivery leader in 60 seconds without saying “dashboard.”
- Find one Control Room reading whose owner is another instrument.
- Name one thing a green source-health reading does not prove.
- Return from an owner instrument using Back and verify project context persists.

## Check questions and expected answers

1. **Where should a new transcript go?** Upstream in KE/Hermes, not pasted into Signal.
2. **Can Hermes change Scope?** No; it can propose through Audit.
3. **Does a live owner read mean fresh?** No.
4. **Does a Scenario persist when inspected?** No; only an explicit owner commit can write supported Reality inputs.
5. **Does Control Room own the displayed likely date?** No; Forecast does.

## Common mistakes

Calling Signal a dashboard; treating currentness as correctness; missing the active Scenario marker; saying target when the screen says likely.

## Hands-on task

Give a two-minute spoken tour: “Here is Reality; here are unresolved choices; here is named or aggregate Capacity; here is the modeled outcome; here is time; here is where I inspect why.” End by returning to Reality.
