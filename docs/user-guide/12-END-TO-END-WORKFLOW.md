# End-to-End Workflow: From Meeting to Brief

This walkthrough uses a representative JSA/iTrack/Platform-style project. The facts are illustrative; the state transitions follow the production contract.

| Step | What Nic sees | What Nic does | Canonical owner change | What does not change | Automatic consequence / why next |
|---|---|---|---|---|---|
| 1. Meeting | New capability need and an unresolved organizational tension | Ensures transcript/source is captured upstream | None in Signal | Scope, Decision, Forecast | Knowledge must exist before delivery implications can be audited |
| 2. KE compilation | Current wiki synthesis with source links | Reviews/corrects synthesis upstream | None | Signal Reality | Wiki remains derivative context |
| 3. Hermes ingestion | Completed watermark and structured intelligence | Waits for completion | None | Snapshot/Reality | Signal refuses split-brain partial state |
| 4. Freshness | Audit says **New intelligence available · Refresh** | Starts refresh | New package/snapshot/Audit records | Prior snapshots; owner Reality | Change comparison is now available |
| 5. Change Inbox | Proposed Investigation capability; evidence/currentness/relevance | Inspects current vs proposed and exact passage | None yet | Forecast | Proposal must cross owner governance |
| 6. Accept Scope change | Completion is sufficient; owner says Scope | Clicks Accept | Accepted Capability in Scope | No work mapping is invented | Coverage becomes modeled subset; Scope is next |
| 7. Organizational tension | Audit proposes a Decision with two directions | Accepts it as a choice | New open, ungated Decision | No DecisionGate; date does not move | Decisions makes tension operable without false delay |
| 8. Stale Finding | Old risk has resolution evidence | Records how it resolved | Finding status/resolution | Scope/Decision/tickets | Attention clears; no unrelated truth changes |
| 9. Scope gap | Investigation shows **NO EXECUTION WORK MAPPED** | Links real current work when it exists, or leaves honest gap | CapabilityWorkLink only if grounded | Capability intent remains | Coverage improves only when current work is represented |
| 10. Actual team | Capacity says `aggregate_unreconciled` | Enters complete named roster and split allocations; confirms reconciliation | People/Allocations become authoritative | No person→ticket links | Forecast now consumes exact effective named FTE |
| 11. Dependency | iTrack explicitly waits for Platform | Verifies direction/evidence; governs edge | Declared Scope dependency | Semantic graph remains separate | iTrack inherits Platform landing and coverage |
| 12. Decision gate test | Open Decision is important but may or may not be serial | Connects only if target work truly waits; supplies why/evidence/3-point duration | Optional DecisionGate | The Decision can remain open without gate | Forecast sees only the explicit serial claim |
| 13. Scenario | “What if James moves from Platform to iTrack?” | Changes one allocation | None | Reality roster | Forecast previews Platform and iTrack consequences; JSA may remain unchanged |
| 14. Forecast | Reality ghost and Scenario body; likely/window/target confidence | Inspects drivers, then discards | None | Reality | Returns to trustworthy baseline before reporting |
| 15. Timeline | NOW, live Forecast, next planned milestone, prior report memory | Checks planned/projected/committed distinctions | Optional TimelineEvent only if real plan changed | Historical Reports | Time story is ready for composition |
| 16. Control Room | Updated Reality, Choices, Capacity, Outcome, Time | Selects dominant constraint and verifies owner detail | None | Owner truth | Confirms the operating picture coheres |
| 17. Report Readiness | Current checks, or named blockers | Follows any blocker to owner; returns | Only owner repairs | Existing reports | Ready means current inputs are safe to freeze now |
| 18. Reports composer | Delivery Leadership + Weekly Update recipe | Reviews modules/caveats; optional labeled note | None before create | Reality | Presentation is tailored without fact mutation |
| 19. Create report | Immutable brief with generated-at and sources | Creates, reopens, verifies | New Report snapshot/recipe | All owner facts | Historical story is frozen |
| 20. Site handoff | Supported interactive bundle action | Initiates explicit user-mediated handoff | External artifact only when user completes workflow | Signal does not auto-publish or auto-sync | Audience receives a traceable story |

## The governing pattern at every step

```text
KNOWLEDGE SAYS → AUDIT PROPOSES → OWNER ACCEPTS → FORECAST RECALCULATES → REPORT FREEZES
```

If you cannot name the owner being changed, stop. If the action is only a question, use Scenario. If the resulting date covers only a subset, say so before saying the date.
