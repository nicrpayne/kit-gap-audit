# Signal User Guide + Training System

This directory is the evidence and release record for Signal's operating guide, training curriculum, and recording system.

Canonical operator documentation lives in `docs/user-guide/`. Training sessions live in `docs/training-curriculum/`; recording materials live in `docs/training-video/`.

## Authority order

1. Authenticated production at the recorded deployment and commit.
2. The exact production Git tree.
3. Staging or disposable fixtures for consequential actions and hard-to-reach states.
4. Accepted-but-not-deployed branches and product briefs, explicitly labeled as future or not live.

Screenshots keep their provenance in the filename or companion index. Fixture imagery is never presented as production.

## Artifact index

- `SOURCE-STATE.md` — production identity, route inventory, verification date, and live/future boundary.
- `SIGNAL-AT-A-GLANCE.md` — the operator's loop from knowledge to communication.
- `WHICH-INSTRUMENT-FLOWCHART.md` — practical routing guide.
- `HUMAN-ARCHITECTURE.md` — where truth comes from, without implementation architecture.
- `COVERAGE-MATRIX.md` — control, state, warning, write, and visual coverage.
- `BUGS-FOUND-DURING-DOCUMENTATION.md` and `BUG-SUMMARY.md` — dogfood findings, kept separate from the manuals.
- `screenshots/raw/` — source captures with provenance.
- `screenshots/annotated/` — teaching versions with numbered callouts.
- `handbook/` — consolidated navigable handbook output.
