# Signal Operating Handbook

Open [`index.html`](index.html) for the designed, navigable handbook home. Source Markdown remains canonical; the handbook deliberately links to it instead of creating a second copy that can drift.

## Publishing rule

1. Update the source guides and production authority first.
2. Run the documentation validator.
3. Re-capture any UI whose contract changed.
4. Update this handbook only when navigation, release authority, or the learning path changes.

The production badge in the handbook identifies the code authority, not a claim that its embedded release-fixture screenshots show current production data.
