# Drag/drop contract

The interaction remains a Scope instrument: a release deck, outside-release rail, open bay, and execution tray. It is not a generic status board.

## Meaningful Reality changes

1. Drag an accepted capability toward `OUT OF RELEASE`, or an outside/future capability toward `IN THIS RELEASE`.
2. The pointer operation creates only a local pending preview.
3. An Impact Preview drawer shows deterministic item count, modeled-load and simulated-date deltas.
4. Choose **Commit Reality** to invoke the governed server owner, or **Keep hypothetical** to retain Scenario only.

## Work mapping

1. Drag a raw Linear row from `NO CAPABILITY YET` onto an accepted Capability card.
2. The target lights and the pointer operation creates a mapping preview.
3. Confirm to persist `CapabilityWorkLink`; cancel leaves Reality untouched.
4. Unlink from the inspector follows the same preview/confirm law and returns the issue to the unmapped tray when no accepted mapping owns it.

Raw source identity is never rewritten. Duplicate links are prevented per Scope. Title similarity does not auto-map anything.

Reordering was intentionally not added: current canonical semantics do not use ordering in Forecast, and an immediate reorder write would add ceremony without changing product meaning. `sortOrder` is now available for a future explicitly designed ordering contract.
