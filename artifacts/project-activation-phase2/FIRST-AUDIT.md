# First Audit

The first Audit runs in the activation transaction after ContextSnapshot 01 is frozen. It compares accepted canonical Reality with external candidates, intelligence, evidence, and coverage.

Deterministic first-finding classes are: accepted capability with no execution link, incomplete provider coverage, unresolved contradiction, non-rejected external dependency, and an activated project with no represented capabilities. Findings point to snapshot evidence IDs and remain unresolved. Bootstrap discovery does not auto-resolve them.

The completion surface lists compact results and hands off to the existing protected Audit World without changing its geometry.
