# Reports handoff

Activated projects are ordinary Scopes, so they appear in the Reports selector and preserve `?project=<scopeId>` through Signal navigation.

For an execution-unconfigured project, report generation returns HTTP 409 and an honest explanation instead of manufacturing a finished Delivery Leadership brief. Existing `DecisionBriefV1 → BriefRecipeV1 → BriefPresentationV1 → InteractiveBriefBundleV1` behavior for ready projects is unchanged and covered by its fixture suites. ChatGPT Site publication is intentionally deferred.
