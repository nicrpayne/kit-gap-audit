# Activation Manifest

The readiness surface has two explicit columns: `WILL BECOME CANONICAL` and `WILL REMAIN EXTERNAL / CANDIDATE`.

Canonical preview includes project identity, aliases, accepted capabilities and execution links, Decisions, ScopeDependencies, dated milestones, and source registrations. External preview includes every non-accepted candidate, people explicitly labeled not staffing, non-dependency semantic relations, provider gaps, ambiguities, and missing information. Execution and Forecast readiness are displayed before activation.

The surface requires acknowledgement when provider gaps or blockers exist and always displays:

> ACTIVATION DOES NOT CERTIFY COMPLETENESS. THE FIRST AUDIT WILL TEST THIS ACCEPTED MODEL AGAINST EXTERNAL EVIDENCE.
