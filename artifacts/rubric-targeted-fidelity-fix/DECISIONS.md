# Translation decisions

## Preserved from Rubric

- One continuous canvas world
- Hex surface, vignette, local fog/glow, layered material hierarchy
- Node-owned drag versus background-owned pan
- Cursor-anchored wheel zoom
- Interrupted-flight handoff
- Retained positions through layout morph
- Constellations bounded free-drop behavior
- Rings return-to-seat behavior
- Selection corona and local optical wake
- In-world object utility card pattern

## Replaced with Signal semantics

- Applications/Routines/Memory/Skills → Aligned/Drift/Conflict plus a separate Sources horizon
- CLAUDE.md and filesystem identity → accepted Reality and canonical Signal objects
- Departments/ARMS layers → Signal lanes, evidence artifacts, external subtypes, and product territories
- Byte/file mass → semantic display importance and truthful group counts
- Generic file removal → presentation-only Hide from view

## Intentionally different

- External/trust is carried by shape, color, copy, and edge material—not radial distance.
- Sources sit on an orthogonal provenance horizon. Their radius does not mean disagreement.
- Generic relationships exert no layout spring. Spatial geography cannot imply causality or live flow.
- Trace exists only when a complete canonical path reaches evidence and a source artifact.
- Human review remains in Signal's existing workflow and is not copied from Rubric.

## Deferred until a real contract exists

- Native Open on device/provider deep links
- Remove from canonical data
- A third dedicated provenance/source layout
