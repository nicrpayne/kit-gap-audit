# Signal Audit — targeted Rubric fidelity fix

## Verdict

**READY FOR PRODUCTION REVIEW**

This pass translates the useful Rubric world into Signal Audit without importing Rubric's product vocabulary or weakening Signal's truth laws. The result is still Audit: accepted Reality at the centre, disagreement as the sole radial meaning, canonical Signal objects, provenance, Search, Trace, and human review. Rubric supplies the canvas, motion, drag ownership, focus grammar, material hierarchy, and world-like composition.

The implementation is confined to Audit components, Audit libraries, and an Audit proof. No ingestion, database, Reality mutation, Decisions, Forecast, Portfolio, Timeline, shared shell, deployment, or production code path outside Audit was changed.

## What changed

- The graph now owns the full Audit canvas. The permanent right rail is gone.
- Project overview is an optional contextual overlay.
- Selection opens a compact in-world utility card. `View here` expands the existing Audit inspector without replacing the map.
- The card supports `Fly to`, `Copy reference`, conditional `Open source`, `Trace provenance` where a complete path exists, and reversible `Hide from view`.
- All canonical objects retain physical seats at every zoom. Zoom changes identity disclosure, not whether population exists.
- Source artifacts are formed, graspable objects on a separate outer provenance horizon.
- Rings are named directly in Signal language: `ALIGNED`, `DRIFT`, `CONFLICT`, `SOURCES`.
- External trust no longer creates a false farther disagreement ring. Unresolved external claims default to Drift unless an explicit Reality relationship says aligned or conflict.
- Ring sectors are fuller and more continuous, closer to Rubric's whole-world composition.
- Lane selection wakes its semantic population; local bloom reaches a larger but still bounded neighbourhood.
- Layout switching preserves the reader's camera. `Fit` remains explicit.
- Exact displayed titles and canonical identifiers win Search before longer incidental matches.

## Direct answer on click/drag

**Yes for the mechanics implemented by the supplied Rubric reference engine.** A node drag is owned by the node rather than misread as a camera pan; Constellations retains the bounded free-drop home; Rings eases a released node back to its semantic seat; an interrupted camera flight yields to the hand. The 125-check spatial/gesture proof and the browser drag sequence both pass.

This does not mean arbitrary connected neighbours follow a dragged leaf. Signal deliberately does not use relationship springs because that would turn citation/related-to edges into false spatial causality. Hubs wake local semantic population visually, but generic edges do not rearrange truth geography.

## Known limits for review

- `Open source` is shown only for a safe `http:`/`https:` URL carried by the selected canonical object. The local fixture intentionally contains no such resolvable URL, so this action is not browser-demonstrable there.
- Native “Open on device” is not invented from provider IDs or local-looking references. It needs a trusted Hermes/provider resolver contract before it can be safe and truthful.
- Constellations is now faithful to Rubric's bounded interaction chassis, but its first-level geography remains Signal's Model/Delivery/Evidence/External territory system by design.
- The database-backed interaction suite could not run in this isolated worktree because `DATABASE_URL` is absent. The read-only fixture browser pass and all DB-free proof suites passed.
