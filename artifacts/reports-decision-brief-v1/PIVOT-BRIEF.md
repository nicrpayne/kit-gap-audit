# JSA → KIT Construct pivot brief prototype

## Current verdict

**A responsible pivot recommendation is not available from current canonical data.**

The prototype deliberately returns missing-input rows because the known production world lacks:

- a canonical KIT Construct Scope/work model;
- named, reconciled allocations.

It does not invent KIT Construct work, staffing, FTE, dates, confidence, defer candidates, support tail, or a recommendation.

## What the current prototype can answer

- JSA’s live Forecast window and confidence from the canonical Forecast owner.
- Accepted remaining executable JSA work count/effort already included by Forecast.
- First-class open JSA Decisions, whether each is gated, exact target/range, owner, needed-by, and evidence count.
- Declared dependencies that actually exist.
- Current/prior Audit delta with grounding and provider warnings.
- Next stored Timeline milestone and overdue planned conflicts.
- Why the staffing/pivot recommendation is blocked.

## Eventual option contract

When canonical KIT Construct Scope and named allocation data exist, the same read model can populate three explicit scenario states without Reports inventing semantics:

| Option | Required canonical inputs |
|---|---|
| Finish-first | Accepted JSA remainder, explicit defers, named staffing through completion, support tail, gate state, live scenario consequence |
| Staged pivot | Named people and transfer dates/FTE, JSA support tail, both project scopes, context-switch loss, gates/dependencies, live scenario consequence |
| Immediate pivot | Explicit JSA defers, named transfer roster/FTE, KIT Construct accepted work, gates/dependencies, live scenario consequence |

For every option the brief must show accepted remaining work, defers, Decisions/Gates, gate target, owner, needed-by, evidence, named people, raw/effective FTE, switching loss, support tail, dependencies, next milestone, live date/window/confidence consequence, Audit delta, grounding/currentness warnings, and unresolved inputs.

## Fixture proof

`pivotPrototypeFixture()` sets the absent KIT Construct world and legacy inferred Capacity exactly. The acceptance script asserts that both missing caveats and both rendered missing rows survive into the immutable payload and Markdown.
