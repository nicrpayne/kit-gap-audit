# Versioning and newer truth

Report snapshot N creates bundle/publication N. The Report relation and both hashes make that lineage exact.

If Signal truth later changes, bundle N remains byte-identical. Signal can compare the publication’s Report timestamp or fingerprint with the newest Report and display “Newer project truth available.” The operator creates a new immutable Report and publication N+1.

V1 never refreshes or edits the factual payload of a previously shared Site. Replacement or a later Site version is an explicit user choice in ChatGPT Sites and must use a newly sealed bundle. History is preserved in Signal.
