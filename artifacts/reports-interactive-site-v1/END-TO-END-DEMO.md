# End-to-end disposable demo

Environment: disposable PostgreSQL 16, local Signal app, deterministic JSA DecisionBrief fixture, authenticated browser session. Production and external ChatGPT Sites were not mutated.

1. Seeded an active JSA Scope and immutable Delivery Leadership / Weekly Update Report.
2. Opened Reports and selected the saved report.
3. Verified the finished brief preserved likely Nov 1, target Nov 15, and no canonical commitment.
4. Selected `Create interactive site`.
5. Signal built and sealed the allowlisted bundle, validated 12 material provenance groups, and persisted `bundle_ready`.
6. The disclosure review showed exact included modules, caveats, full JSON, and excluded/private categories.
7. Browser proof stopped before the confirmation checkbox. No file was sent to OpenAI, no ChatGPT task was created, and no Site was deployed/shared.
8. The deterministic recipient preview reconciled the healthy, executive, incomplete, stale, and frozen Scenario bundles with zero browser errors.

Exact final manual action for the first real handoff:

1. Review the bundle in Signal and check the confirmation box.
2. Select `Confirm & open ChatGPT Sites`.
3. Attach the downloaded `signal-site-handoff-<publication>.json` in ChatGPT Sites; paste the already-copied prompt.
4. Review the private draft and save a version without deployment.
5. Reconcile every material value to Signal’s bundle.
6. Only after explicit approval, deploy in ChatGPT Sites and choose the narrowest access.
7. Paste the confirmed HTTPS Site URL into Signal and record `Published / shared`.
