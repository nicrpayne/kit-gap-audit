# Site UX

## Recipient artifact

The reference preview is calm, editorial, and read-only. It does not reuse Signal’s instrument chrome. The flagship first viewport answers:

1. when delivery is likely;
2. why;
3. what can change it;
4. what is actually committed;
5. what changed;
6. what leadership is asked to do;
7. what happens next.

Likely, target, and committed occupy separate cards. Missing commitment is not an empty space. Stale or unavailable truth receives an explicit banner before detail.

## Operator action

`Create interactive site` is available only on a selected immutable DecisionBrief with a saved recipe. The review shows snapshot fingerprint, seal, material-claim count, exact share summary, full JSON, warnings, and exclusions. A confirmation checkbox gates the handoff.

After confirmation, Signal downloads the one-file handoff, copies its instructions, opens ChatGPT Sites, and records `handoff_opened`. Later states are explicit operator attestations. `published_shared` requires a valid HTTPS URL.
