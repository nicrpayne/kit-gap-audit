# Dependencies

Orbit consumes both canonical mechanisms with different meanings:

- a solid dependency comes from `Scope.dependsOnScopeIds`;
- an amber serial clamp comes from an open serial `DecisionGate` whose `targetScopeId` is in the focused path.

The permanent fixture contains JSA → Platform and a separate gate targeting iTrack. JSA Orbit shows the declared dependency and states that one open serial gate targets another delivery path and is intentionally not drawn. iTrack focus owns that gate. No density nodes are fabricated.
