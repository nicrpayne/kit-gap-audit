# Audience matrix

| Audience | Question | Promoted | Demoted | Default density | Expected asks |
|---|---|---|---|---|---|
| Operator / PO | What do I understand and do next? | Audit, all Decisions, evidence, dependencies, Scope, Capacity, Timeline | Executive compression | Expanded | Operator actions and verification |
| Delivery Leadership | When, why, what changes it? | Outlook, commitment state, movement, drivers, levers, confirmed asks, next | Passage-level evidence | Expanded | Gated/cross-scope/near-term candidates, only confirmed as asks by PO |
| Executive | On track, material change, need me? | Outcome, commitment state, deterministic read, 0–2 confirmed asks, one lever | Work-item detail | Compact | Only operator-confirmed executive asks |
| Stakeholder / Partner | What affects expectations or my work? | Expectation, change, next, external dependency, operator note | Internal evidence/staffing/test health | Compact | Explicit externally appropriate asks only |
| Portfolio / Staffing | Where is capacity and what can move? | Reconciled FTE, Scope, scenarios, dependencies, source health | Audit plumbing | Expanded | Staffing/scenario actions only when canonical |
| Decision / Scenario | Which supported option should we choose? | Gates, target Scope, scenarios, dependencies, evidence, missing inputs | General narration | Expanded | Decision owner/needed-by/gate; no invented recommendation |

See `AUDIENCE-LENSES.md` for rationale.
