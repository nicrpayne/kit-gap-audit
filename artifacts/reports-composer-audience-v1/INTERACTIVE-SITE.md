# Site-ready interactive brief

The Site-shaped prototype uses the same `AudienceBriefView`, snapshot fingerprint, recipe order, and module contents as the in-app finished brief. It opens the headline modules first and leaves deeper content expandable. Print expands included detail.

`InteractiveBriefBundleV1` packages the exact snapshot, recipe, derived presentation, permitted references, audience metadata, and explicit security flags. The companion handoff prompt asks `@Sites` for private review, responsive progressive disclosure, no live reads, and no deployment.

This tranche deliberately produces a **Site-ready package**, not an integration with an assumed Sites API. See `INTERACTIVE-BRIEF-BUNDLE.md`, `SITE-HANDOFF.md`, and `screenshots/site-handoff-preview.png`.
