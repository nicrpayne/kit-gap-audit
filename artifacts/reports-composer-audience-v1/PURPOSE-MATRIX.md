# Purpose matrix

| Purpose | Modules promoted by default | Use |
|---|---|---|
| Weekly Update | Outlook, movement, change, next | Cadenced delivery communication |
| Delivery Review | Outlook, drivers, Scope, Capacity, dependencies | Operating review |
| Steering Committee | Outlook, commitment state, asks, drivers | Governance and intervention |
| Launch Readiness | Commitment state, Timeline, dependencies, caveats, source health | Go/no-go readiness inputs |
| Decision Meeting | Asks, Decisions, drivers, evidence | Choice with traceable support |
| Scenario Review | Levers, Capacity, Scope, drivers | Compare only existing owner scenarios |
| Handoff | Next, Scope, Decisions, dependencies, source health | Transfer context and unresolved work |
| Executive Update | Outlook, commitment state, Signal's Read, asks | High-compression leadership update |

Purpose promotion reorders modules already available in the audience preset; it does not silently add audience-inappropriate detail.
