# Clickable prototype

This is a build-excluded static prototype. It is not imported by Next and makes no API or database calls.

Open `index.html` directly, or serve this directory with any static server. The left rail and in-screen calls to action navigate through:

1. Add Project
2. Knowledge scan
3. Bootstrap Review
4. Proposed Scope
5. Ready to Activate
6. First Audit handoff
7. Search V2 drilldown

Interactive behavior includes candidate disposition, navigation, the Add form, the activation handoff, provider coverage, and Search. Local state is illustrative only and can be cleared with `Reset prototype`.

Fixture: **Harbor Relay**, a wholly invented field-handoff coordination product.
