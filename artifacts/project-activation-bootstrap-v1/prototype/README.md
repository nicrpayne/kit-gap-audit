# Clickable prototype

This is a build-excluded static prototype. It is not imported by Next and makes no API or database calls.

Open `index.html` directly, or serve this directory with any static server. The prototype begins in the normal Signal Control Room with Add Project open from the project control. The activation instrument exposes:

1. compact Add Project sheet;
2. asynchronous knowledge scan;
3. primary Bootstrap Review workspace, including Proposed Scope;
4. activation manifest and explicit activation;
5. first Audit handoff.

Global Search V2 is separately available from the suite rail and `⌘K` control. It deliberately does not appear in the activation state sequence. Interactive behavior includes project-control sheet opening, Create & scan, safe partial Review entry, candidate dispositions, ready check, activation, and global Search navigation.

Fixture: **Harbor Relay**, a wholly invented field-handoff coordination product.
